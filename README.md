# Hybrid RAG Document Assistant

A document-grounded Retrieval-Augmented Generation (RAG) system that combines
keyword retrieval, semantic retrieval, rank fusion, neural reranking, relevance
gating, and grounding evaluation to answer questions from PDF documents.

The system is designed to reduce two common RAG problems:

1. Retrieving irrelevant context.
2. Generating answers when the required information is not present in the documents.

---

## 🚀 Overview

This project implements a hybrid RAG pipeline using:

- BM25 for keyword-based retrieval
- FAISS for semantic vector retrieval
- Reciprocal Rank Fusion (RRF) for combining retrieval results
- Cross-Encoder for document reranking
- Relevance gating for out-of-domain questions
- Qwen2.5-1.5B-Instruct for answer generation
- Semantic similarity for grounding evaluation
- Custom retrieval and answer-quality metrics
- Latency measurement for individual pipeline components

The system was evaluated using the research paper:

> Attention Is All You Need — Vaswani et al.

## Key Features

- Hybrid retrieval using BM25 and FAISS
- Reciprocal Rank Fusion (RRF) for combining retrieval results
- Cross-Encoder reranking for improved document relevance
- Relevance gate to reject questions outside the document
- Local LLM generation using Qwen2.5-1.5B-Instruct
- Semantic grounding evaluation of generated answers
- Retrieval, answer-quality, and latency evaluation

## How It Works

The system uses two different retrieval strategies:

### BM25

BM25 performs keyword-based retrieval and works well when important terms
from the query appear directly in the document.

### FAISS

FAISS performs semantic retrieval using embeddings generated by
`all-MiniLM-L6-v2`.

This allows the system to retrieve documents based on semantic similarity
rather than only exact keyword matches.

### Reciprocal Rank Fusion

The BM25 and FAISS results are combined using Reciprocal Rank Fusion (RRF).

```text
BM25 Results
      +
FAISS Results
      ↓
     RRF
      ↓
Combined Candidates

### Cross-Encoder Reranking

The combined candidates are passed through a Cross-Encoder which evaluates
the relevance of each query-document pair.

The highest-scoring documents are selected as the final context.

### Relevance Gate

Before sending the retrieved context to the LLM, the system checks whether
the retrieved documents are relevant enough to answer the question.

If the retrieved documents are not sufficiently relevant, the system refuses
to generate an answer instead of relying on the LLM's pretrained knowledge.
